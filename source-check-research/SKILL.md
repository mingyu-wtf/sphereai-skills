# Source-Checked Research

Sort what you found into "safe to rely on" and "couldn't confirm". The result is a one-page brief the user can read and act on right away.

## Language
Reply and write all deliverables in the user's language (Korean, English, Japanese, …). Ask once if unclear. Quote sources in their original language when the exact wording matters, and add a translation in the user's language.

Worked example: `references/example_en.md` ("Does phone use at night make it harder to fall asleep?"; it shows how unverified items are marked).

## 0. Decide first
1. The question, in one sentence (e.g. "Which of these two products is better for video editing?")
2. Purpose: video script / purchase decision / writing / a decision
3. Scope: time range (last few months?), region (the user's country / worldwide), languages
4. Output length: one-page summary / detailed

## 1. Split the question
Break the big question into 3–6 smaller questions that can actually be answered. For each one, write what kind of material would answer it (official documentation, statistics, user reviews, comparison tests).

## 2. Search
- Search in the user's language and in English. For many topics, more primary sources exist in English. If the topic is local to another country, also search in that country's language.
- Use the search engines people in that market actually use, in addition to Google: e.g. Naver for Korean topics, Yahoo! JAPAN for Japanese topics. If you can't reach one, say so in the method section.
- Rephrase and try at least 3 times (the official name, nicknames, and the problem situation).
- For recent issues, check dates. Treat undated posts as old.
- Use community posts (forums, issue trackers, reviews) to find real-world problems, not as evidence for facts.

## 3. Grade every source
| Grade | Examples | How to use it |
|---|---|---|
| A Primary | Official documentation, announcements, papers, laws and regulations, original data | Use as evidence for facts |
| B Reliable secondary | News outlets, specialist media | Use alongside the primary source if you found it; if not, write "according to reports" |
| C Personal opinion / review | Blogs, communities, social media | Use for trends only; don't quote numbers from them |

Attach a source to every statement. If you can't find one, leave the statement out or mark it "unconfirmed".

## 4. Cross-check
- Check important numbers and dates against at least 2 independent sources.
- If sources disagree, don't hide it: write "A says ○○, B says ○○".
- Several articles copied from the same story count as one source.

## 5. Output format
```
## Conclusion (3 lines max)
## Key facts
| Fact | Source | Grade |
## Where sources disagree
## Unconfirmed / still need to find out
## Method (search terms, date range, languages, search engines)
## Source list
```
- The conclusion contains only what has evidence. Label guesses as "guess".
- Put the research date at the very top.

## 6. Don't
- Fill gaps with plausible numbers that have no source
- Pass along a single source's claim as fact
- Use advertorials or comparison-site rankings as evidence

## 7. Checklist
- [ ] There is a conclusion that answers the question directly
- [ ] Every key number has a source and a grade
- [ ] Where sources disagree, both sides are written down
- [ ] Unconfirmed items are listed separately
- [ ] The research date is written
