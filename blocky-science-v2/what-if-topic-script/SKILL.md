# What-if Topic and Script

## 1. Pick the topic
A good What-if topic has:
- **A one-line premise anyone understands**: "What if mosquitoes disappeared tomorrow?"
- **Real science behind it**: papers, agencies, measured numbers.
- **A twist**: the obvious answer is wrong or incomplete.
- **Things to show**: objects, places and scale that can be built from blocks.

Before choosing, search your own video list so the topic and title do not repeat.

## 2. Structure
| Block | Content |
|---|---|
| Hook | The premise in one sentence + the most surprising consequence |
| Consequences | What happens, from the first effects to the long-term picture |
| The twist | The unexpected answer |
| In reality | What scientists are actually doing or have measured |
| Ending | A question for the comments |

Split the consequences into several blocks so the video moves forward.

## 3. Length
Measure how many characters your narration voice reads per second, then estimate: characters / speed. Fix the script, not the audio, if the estimate is off.

## 4. Fact check (before narration, always)
- Check every number, quote and study against the original source. Record it in a table: claim | source | link.
- **Delete** any claim you cannot source.
- Mark estimates as estimates.
- Quotes word for word, with the person's name and organisation.

## 5. script.md layout
```
## Narration
### [1] Hook
...
## Shot table
| Block | Shot | What we see | Camera |
## Fact check
| Claim | Source | Link |
## TTS replacement
| Screen | Spoken |
```
- On-screen text uses digits. The TTS replacement table gives how each one is read aloud.
- Children or patients are shown as symbols (coloured blocks, faceless icons), not as detailed people.

## Output
`script.md` with narration by block, shot table, fact-check table with links, and the TTS replacement table. Next: `free-tts-narration`.
