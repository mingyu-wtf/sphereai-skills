# 설치 안내 (Humanize KR)

원작: epoko77-ai/im-not-ai (MIT) — https://github.com/epoko77-ai/im-not-ai

## 가장 쉬운 방법: AI 에이전트에게 맡기기
이 폴더를 VS Code로 열고 AI 에이전트에게 이렇게 말하세요.

> 이 폴더의 설치_안내.md대로 humanize-korean 스킬을 설치해줘

## 에이전트가 할 일 (Claude Code 기준)
1. 이 폴더 전체(`함께_설치` 폴더 제외)를 `~/.claude/skills/humanize-korean/`로 복사한다.
2. `함께_설치/skills/` 안의 `humanize`, `humanize-redo`, `humanize-scan` 폴더를 `~/.claude/skills/`로 복사한다.
3. `함께_설치/agents/` 안의 `.md` 파일 4개를 `~/.claude/agents/`로 복사한다.
4. 같은 이름의 폴더나 파일이 이미 있으면 덮어쓰기 전에 사용자에게 먼저 묻는다.
5. Python 3이 있는지 확인한다(`python --version` 또는 `python3 --version`). 스크립트는 표준 라이브러리만 쓴다.
6. 새 세션을 열면 쓸 수 있다고 알려 준다.

`~`는 내 사용자 폴더입니다(Windows는 C 드라이브의 Users 안 내 이름 폴더, macOS는 /Users 안 내 이름 폴더).

## 쓰는 법
- "이 글 AI 티 없애줘" + 글 붙여넣기 → 윤문
- "이 글 AI 같아?" → 고칠 값어치가 있는지 먼저 점검(humanize-scan)
- "2차 윤문해줘" → 방금 결과를 한 번 더 다듬기(humanize-redo)
- 정밀하게 하려면 "정밀 모드로" 또는 `--strict`
