# Post shape (visit post)

1. **Title** - lead with the most searched fact, then the place name and what the post answers.
   Example: `"하이볼 한 잔 12,000원, 수·목은 쉽니다" 강화도 류 증류소 카페&BAR 가는 방법, 주차는 무료`
2. **One-line summary box** - hours, days off, price range, parking in two or three sentences.
3. **Intro** - greet, why people look for this kind of place, then the user's own impression ("결론부터 말하면 너무 좋았습니다"). List what the post covers and how facts were checked (Place, check date, number of reviews read).
4. **Body sections** - 5-8 subheadings, each answering one search question. Use the search words from step 4 where they read naturally.
   - How to get there / entrance (with photos)
   - Hours and days off (small table or info image + the same text below it, because text in images is not searchable)
   - Menu and prices (table)
   - Inside, seats, toilets, view (photos + captions)
   - What visitors liked / found disappointing (summary of reviews, no copied sentences)
   - The user's own review (only what the user said)
5. **FAQ** - 3-5 short questions (parking? kids? reservation? pets?) answered from confirmed facts only.
6. **Map + Place link**, then tags (10-20), mixing area words, place name and purpose words.

Line length: write for mobile, 15-25 Korean characters per line, short paragraphs.
Never: promise rankings, invent prices, invent personal experiences, or post content copied from other reviews.
