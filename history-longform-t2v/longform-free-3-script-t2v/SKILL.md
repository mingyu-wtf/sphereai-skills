# [무료] 대본 작성 (T2V용)

이미지→영상 대본과 같지만, **블록 1개 = 영상 클립 1개(터보 약 7초 / 20스텝 8초)** 로 쓴다. 나레이션이 클립보다 길면 편집 단계에서 클립을 느리게 늘려야 해서 화면이 어색해진다.

## 필요한 것
- outline.md (기획 스킬 `longform-free-2-plan` 의 결과). 기획 스킬은 기존 것을 그대로 쓴다. 구성안이 30블록이면 클립 30개(터보 약 7시간).
- 비용: 없음

## 형식
- `script.txt`: 블록 사이를 **빈 줄**로 구분. 한 블록 = 한 장면 = 클립 1개.
- 분량: **나레이션이 클립 길이 이하**여야 한다. 한국어 읽기 속도는 대략 초당 5~6음절이라 7초 클립이면 공백 포함 40~50자 안팎이 안전하다(추정치. 나레이션 스킬을 돌려 `timing.json` 의 `dur` 가 클립보다 길면 그 블록만 줄인다).
- 말투: 시청자에게 직접 이야기하듯, 짧은 문장. 초등학생이 알아들을 쉬운 말. 첫 블록은 훅, 마지막 블록은 설교 없이 여운.
- 블록마다 **눈에 보이는 장면**이 하나 떠올라야 한다(누가, 어디서, 무엇을 하는지). 추상적인 설명만 있는 블록은 영상으로 만들 수 없으니 장면이 보이는 문장으로 바꾼다.
- 시대 고증: 현대 물건·표현을 장면에 쓰지 않는다.

## 자동 점검(스스로 고친다)
- 길이가 위 기준을 넘는 블록은 줄이거나 나눈다. 어려운 한자어는 쉬운 말로 바꾼다.
