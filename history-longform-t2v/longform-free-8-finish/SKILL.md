# [무료] 후보정·썸네일·업로드 문구

## 필요한 것
- draft.mp4, 컷 이미지 1장(썸네일용)
- ffmpeg, Pillow
- 비용: 없음

## 순서
1. **미리보기**: `python compress_preview.py draft.mp4 preview.mp4 --mb 30` — 확인용 작은 파일.
2. **썸네일**: `python thumb.py images/C001.jpg "제목 첫 줄\n둘째 줄" thumb.png` — 굵은 글씨 + 외곽선, 1280×720. 글자는 12자 이내 두 줄이 읽기 좋다.
3. **업로드 문구**(`upload.txt`):
   - 제목: 호기심을 끄는 한 문장(40자 안팎).
   - 설명: 한 줄 요약 + 내용 3줄 + 출처 + "AI로 재구성한 이미지" 안내 + 해시태그 3개.
   - 태그: 쉼표로 구분한 키워드 10개 안팎.
4. 업로드는 사용자가 직접 한다.

## 끝
처음 만든 영상이라면 여기서 완성입니다.
