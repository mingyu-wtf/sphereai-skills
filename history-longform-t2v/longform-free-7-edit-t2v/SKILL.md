# [무료] 가편집·자막 (T2V 클립용)

이미지를 확대하는 `longform-free-7-edit` 과 달리, **이미 움직이는 클립**을 나레이션 길이에 맞춰 이어 붙이고 자막을 입힌다. ffmpeg 만 있으면 된다(Node·리모션 불필요).

## 필요한 것
- `clips/` 의 mp4(이름순 = 대본 블록 순서. `longform-free-6-video-t2v` 결과), `script.txt`(블록은 빈 줄), `narration/narration.mp3` + `narration/timing.json`(나레이션 스킬 결과)
- ffmpeg(ffprobe 포함). 한글 폰트(Windows 맑은 고딕 기본)
- 비용: 없음

## 순서 (묻지 말고 자동으로 진행)
1. `python scripts/t2v_edit.py --out draft.mp4`
   - 블록마다 클립 길이를 나레이션 길이(+0.25초)에 맞춘다: 속도 0.8~1.25배 안에서 늘리거나 줄이고, 그래도 모자라면 마지막 장면을 멈추고, 넘치면 끝을 자른다. 한계에 걸린 클립은 `[주의]` 로 알려 준다 → 그 블록의 대본을 줄이거나 클립을 다시 뽑는다.
   - 클립 자체 효과음은 25% 로 낮춰 나레이션 밑에 깐다(`--sfx 0.4` 처럼 조절).
   - 대본을 24자 안팎 한 줄 자막으로 나눠 아래쪽에 입힌다(흰 글씨 + 검은 외곽선). 자막이 필요 없으면 `--no-subs`, 글꼴은 `--font`.
   - 썸네일용 프레임을 `images/C001.jpg` 로 뽑아 둔다(8단계가 쓴다).
2. `draft.mp4` 를 사용자가 확인한다. 어색한 클립만 `--only` 로 다시 뽑아(6단계) 같은 명령을 다시 실행한다.
3. 클립 수와 나레이션 블록 수가 다르면 앞쪽 공통 개수만 조립하고 알려 준다.

## 알아둘 것
- 자막 타이밍은 블록 안에서 글자 수에 비례해 나눈 근사치다(단어 단위 싱크 아님).
- 세로 영상은 `--size 1080x1920`.
- 이 스크립트는 클립 2개 + 톤 소리 나레이션으로 시험했다(영상·자막·길이 정상 확인). 30블록 전체 규모와 실제 TTS 나레이션으로는 아직 돌려 보지 않았다.
