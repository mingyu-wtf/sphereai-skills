# [무료] 대본 작성

## 필요한 것
- outline.md (기획 스킬의 결과)
- 비용: 없음

## 형식
- `script.txt`: 블록 사이를 **빈 줄**로 구분. 한 블록 = 한 장면 = 약 10초 분량(공백 포함 250자 안팎).
- 말투: 시청자에게 직접 이야기하듯, 짧은 문장. 초등학생이 알아들을 쉬운 말.
- 첫 블록은 훅. 마지막 블록은 설교 없이 여운.

## 자동 점검(스스로 고친다)
- 한 블록이 너무 길거나 짧으면 나눈다/합친다. 어려운 한자어는 쉬운 말로 바꾼다.
