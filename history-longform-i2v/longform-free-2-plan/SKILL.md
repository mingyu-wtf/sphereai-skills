# [무료] 소재·구성안 기획

## 필요한 것
- 웹 검색이 되는 Claude 환경(없으면 사용자가 자료를 붙여넣기)
- 비용: 없음

## 순서
0. 사용자가 소재를 말했으면 그것으로 바로 진행한다. 없으면 후보를 직접 고른다.
1. 소재 후보 5개를 낸다(인물/사건/물건 중 하나). 각 후보에 "시청자가 처음 듣고 놀랄 점"을 한 줄 붙인다.
2. 가장 놀라운 후보 1개를 스스로 골라(사용자가 이미 정했으면 그것으로) 멈추지 않고 구성안을 30칸(블록)으로 만든다. 블록 하나 = 나레이션 약 10초.
   - 앞 3블록: 훅(가장 놀라운 사실이나 질문)
   - 중간: 배경 → 위기/문제 → 해결 → 결과
   - 마지막 2블록: 여운(교훈을 설교하지 말고 남는 질문이나 장면으로 끝냄)
3. `outline.md` 로 저장한다(블록 번호 + 한 줄 요약).

## 지킬 것
- 이름·연도·숫자는 확실한 것만 쓴다. 모르면 "정확한 기록은 남아 있지 않다"로 쓴다.
- 초등학생도 이해할 만한 소재 설명을 기준으로 한다.
