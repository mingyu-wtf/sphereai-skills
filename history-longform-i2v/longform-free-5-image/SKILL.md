# [무료] 다중 스타일 이미지(구글 플로우)

## 필요한 것
- 어사이드(Aside) 설치·실행 + 어사이드 브라우저에 구글 로그인(플로우가 열리는 계정). `aside account list` 로 계정 확인
- 대본 또는 컷 설명
- 비용: 없음(플로우 무료 플랜은 생성 횟수 제한이 있을 수 있음)

## 순서 (묻지 말고 자동으로 진행)
1. **화풍 고르기**: `styles/` 의 8가지(oil 유화, ink 수묵, watercolor 수채, classical 고전회화, woodblock 판화, webtoon 웹툰, clay 점토, photoreal 실사) 중 하나. 사용자가 말하지 않았으면 대본 분위기에 맞춰 직접 고른다. 새 화풍은 `styles/이름.md` 에 문구 한 줄만 쓰면 추가된다.
2. **컷 설명 쓰기**: `cuts.txt` 에 한 줄에 한 컷. 장면을 한 문장으로(누가, 어디서, 무엇을). 길게 쓰지 않는다. 대본 블록에서 직접 뽑는다.
3. `python scripts/build_prompts.py cuts.txt oil` → `prompts.txt` (화풍 문구 + 컷 설명 + 공통 금지 문구 자동 조립).
4. **자동 생성·저장**: `python scripts/flow_images.py prompts.txt --out images [--account u0]`
   - 어사이드가 구글 플로우에서 새 프로젝트를 만들고(주소를 `flow_project.txt` 에 기억), 프롬프트를 한 컷씩 넣어 16:9 로 생성해 `images/C001.jpg …` 로 저장한다. 컷당 약 40~60초.
   - 이미 있는 컷은 건너뛰므로 중단돼도 같은 명령으로 이어진다. 특정 컷만: `--only C003`
   - 무료 한도에 걸리면 멈추고 알려 준다 → 시간이 지난 뒤 같은 명령으로 이어서 한다.
5. **눈으로 확인**: 만든 이미지를 직접 열어 글자/워터마크/현대 물건이 있는 컷만 골라 `--only` 로 다시 만든다(지우고 다시: `images/C00N.jpg` 삭제 후 실행).
6. 곧바로 `longform-free-6-video` 로 넘어간다.

## 팁
- 같은 화풍 문구를 모든 컷에 붙이면 화면 통일감이 생긴다. 중간에 화풍을 바꾸지 않는다.
